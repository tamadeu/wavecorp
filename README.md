# Wavecorp

Site institucional one-page da Wavecorp, desenvolvido com React, TypeScript e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run build
npm run lint
```

## Estrutura

- Apresentação e posicionamento da Wavecorp
- Públicos atendidos
- Frentes de atuação
- Rede de executivos e indicadores
- Setores e contato
